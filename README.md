## What it does

`main.ts` writes a single job title — 60 characters at most, nothing else —
to `/output/entry.txt`. The title is picked deterministically from a shortlist
of original candidates, each scored against the judge's published criteria in
the judge's own priority order: weirdness, stranger than ordinary work,
humour on first read, sounding like a real job, and instant readability.

The winning title:

> **Senior Penguin Relocation Coordinator**

A real-sounding job title with one gloriously specific twist: relocating
penguins is a job you can instantly picture someone doing — hi-vis vest,
clipboard, taking it completely seriously.

## Run it

```sh
node main.ts
```

No dependencies, no network, no environment input: the same run always
writes the same file, so the two grading runs agree byte for byte.
